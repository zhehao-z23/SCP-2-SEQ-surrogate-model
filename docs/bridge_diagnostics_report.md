## 当前值得带入下一轮的观察

**长度不是一个统一的误差解释。** residue_mean 的H与长度Spearman仅约0.019/0.034；seed1701的折间范围−0.031至0.072。但尾箱误差与长度的Spearman约0.328/0.336，seed1701各折约0.303–0.369，控制其他变量后仍约0.332。CDF相关居中。长链子群平均更难与全体H相关很弱可以同时成立：相关是逐T层面，而主指标是组宏平均，关系也并非全范围单调。

**覆盖和组大小的全局H相关都较弱。** coverage相关约0.021/0.006；组大小约0.060，两seed方向相近。低覆盖组并非必然更差，缺失U关联也不代表模型无法预测T标签。这些结果反对把一个单独coverage或group-size阈值直接解释为误差原因或部署拒识概率。

**补充目标尺度控制。** 真实首末箱总质量与长度Spearman为0.299；将真实尾质量作为单独秩残差控制后，残基mean的长度—绝对尾误差相关由0.328/0.336降为0.223/0.243。原关联有一部分来自目标尺度，但未被完全解释。这是使用评价真值的描述分析，不能作为未来模型输入或因果调整。seed1701的>600 aa组平均真实/预测尾质量为0.02190/0.01950；负尾有符号偏差−0.002218，正尾−0.000187。长链负尾低估值得关注，但其他样本有相反偏差，不能据此简单加强全局平滑。补充表与图为`tail_scale_diagnostic.json`和`tail_scale_diagnostic.png/svg`；不增加模型训练。先看新物理标签的分箱/尺度桥接，再决定有限尾部校准或复合loss对照，不能把旧63箱尾部权重直接套到新63箱。

**存在优化余量，但它不是所有误差的答案。** 3次匹配续训的H/CDF/尾箱误差一致改善，支持将优化预算作为实际原因候选；额外更新、AdamW重启和LR共同变化，未被拆成独立因果效应。训练与stop单位不同，本报告没有用视觉gap证明过拟合。

**聚合机制有可利用信号，极端形状仍需人工核查。** 同参数、共同输入的残基非线性后mean优于先mean，支持当前早期平均可能损失预测信息；优化路径与正则化仍是替代解释。固定极端案例中可见预测峰质量过低和过高两种形状偏差，不能仅用“模型太平滑”概括，更不能把极端案例发生率外推到全体。

**输入标签与跨来源问题尚未被这些图解决。** 标签仍对应teacher T结构的历史顶点p，T=U仅表示当前hash相等；未检查坐标、重新求解物理或完成来源桥接。结构坐标不是本诊断已绑定的输入，因此没有生成猜测性结构图片；案例保留精确标识与结构hash供下一步人工溯源。高特征cosine也不是同源边或标签准确性的证据。
