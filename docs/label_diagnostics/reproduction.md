# Reproduction boundary

The seven scientific source files are byte-for-byte copies of their completed executions. Their actual source and archive SHA values match in `source_provenance.json`. The eighth source, `export_bridge_diagnostic_public.py`, is a local archival projection of pinned aggregate JSON; it does not repeat scientific computation. The successful optimization addendum is v2. Its preceding field-name collision and failed record remain preserved privately.

These are scripts for a controlled existing project, not a self-contained dataset or reproduction package. The private historical release, exact-count/QC snapshots, retained-sequence metadata, protected-role contract and guard, immutable fold membership, saved model predictions and original evidence indexes are required and are not included. Source file hashes and interfaces do not grant access or certify new inputs. Original sequence strings, raw potential matrices, embeddings, weights and per-object data are absent from this archive.

| Source | Required private inputs and scope |
|---|---|
| `bridge_binned_quantile_bounds.py` | Mathematical support intervals from supplied integer counts and bin edges; type-7-compatible order-statistic bounds without uniform-within-bin assumptions. |
| `bridge_representation_audit.py` | Pinned release/meta, role guard, raw-count/QC snapshots, target index and existing p; checks all current development rows. |
| `bridge_coarse_shape_support.py` | Pinned release and role guard plus [`bridge_coarse_shape_plan.json`](../../configs/bridge_coarse_shape_plan.json); original finite-bin masses and exact coarsenings only. |
| `bridge_duplicate_T_audit.py` | All repeated exact-T groups in the pinned cohort, guarded count/QC/manifest rows and current p; case identities remain in private output. |
| `bridge_duplicate_T_input_closure.py` | Prior duplicate-audit receipt, charge array and accepted residue-cache index; does not load or rehash large embedding arrays. |
| `bridge_shape_model_comparison.py` | Original 30-fit roles/prediction/evidence index and representation-audit receipts; replays probability metrics before shape comparisons. |
| `bridge_shape_optimization_addendum.py` | A private pinned run/evidence plan, original 12 optimization predictions, four old references, shared shape helper and completed OOF/representation receipts. |
| `export_bridge_diagnostic_public.py` | The six named private aggregate summaries with exact SHA values; explicit field projection into five public result JSON files. |

The scripts take source roots or plans as arguments. Private execution plans contain evidence paths and run bindings and are deliberately excluded. The scientific scripts retain the original CPU 172 or 174 affinity assumptions and resource checks; a different host requires a separately recorded adaptation and new authorized resource binding. Do not use these copies to overwrite the original frozen execution directories. The original analyses ran with one BLAS thread, no GPU, 8 GiB address-space caps and 600-second limits. NumPy, pandas and pyarrow from the existing controlled runtime are required for the data scripts; no environment installation is performed by this archive.

Role checks precede all target/prediction payload access. A development guard pass does not authorize protected labels or a final training release. The histogram contract is the historical retained-vertex 63-bin contract: 61 finite bins plus two open tails. Finite-bin density uses actual width; tails have mass only. First/last-bin error is not the historical ±5 selection metric.

The exact-count quantile bounds and uniform-bin proxy answer different questions. The former are conservative feasible intervals compatible with saved count/rank information. The latter is an explicit approximation for both true63 and predicted63, used consistently for this shape comparison. Its error cannot be called wholly due to binning, and its performance is not an optimal attainable limit. Absolute Bowley conditions omit historical source-population percentiles.

Continuous errors are computed per original row, then averaged within T, then within homology group, then across groups. Per-metric finite support is retained. Candidate ranking uses a fixed canonical row per T; true membership is an any-view condition and is separate from the score. The original OOF pool has 220 candidates per direction; optimization comparisons use 44 per matched fold. Seeds reuse objects. Class-presence group/T counts can overlap and are not independent replicate counts.

Detailed outputs produced by these scripts remain private. The explicit archive excludes all sample identities, memberships, candidate tables, probabilities, per-group rows, original source/QC rows, plots and local HTML. The result JSON contains only counts, error aggregates, support, declared limits and source SHA references. The README is a new aggregate narrative, not an unmodified copy of private reports.
