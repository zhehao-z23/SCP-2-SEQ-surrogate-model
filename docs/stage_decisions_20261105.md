# Atlas 规模实验：三条决策与阶段收束

日期：2026-11-05。目标是尽快收窄最终模型候选、形成可发表证据，并为指定 sequence-space release 的扫描作准备。本阶段完成的是历史 **T→顶点等权 p** 开发实验；新正式任务仍为 **C→实验结构面积加权 p**。两者不能混榜，也不能把历史权重直接登记为新 C 的合法初始化。

版本状态：原计划48 fit与另登记的4 fit读出对照均完成并通过结果核验，最终summary为52/52；26个按stop选定的配置全部early-stop。依据为 `scale_plan.json`、`capacity_amendment.json`、`history_increment_20261105.md`、`round_20261105_research.md`及 Byte `${RUN_ROOT}/results/`。

## 决策卡1：数据规模是否改变候选排序

**已取得的证据。** 同一T release、固定stop/评价集、按同源组嵌套扩大训练；2折、seed1701、每配置2个LR且仅按stop选LR。共同评价3,199组，H越低越好。

| 输入/读出 | 200训练组 | 1,000训练组 | 全部训练组（每折4,799或4,800组） |
|---|---:|---:|---:|
| 组成+长度，小MLP | 0.065417 | 0.056807 | 0.052732 |
| 组成+电荷，小MLP | 0.064247 | 0.055888 | 0.052633 |
| ESMC300 mean，深MLP | 0.078511 | 0.064674 | 0.057264 |
| ESMC300 mean+电荷，深MLP | 0.067130 | 0.056935 | 0.050140 |

扩大数据后，融合配置由落后转为领先小MLP电荷基线；全规模H下降4.74%，配对组ΔH=-0.002494，描述性95%区间[-0.003074,-0.001888]。两个外折分别改善，CDF与首末bin质量误差也分别改善。mean单独输入仍落后。该现象支持继续保留融合候选，不证明所有pLM优于简单特征，也不能与旧1,061条完整U结果直接解释为纯规模效应。

**已补充的替代解释对照。** 小MLP为[256,128]/dropout0.1，深MLP为[1024,512,256]/dropout0.3；增益可能部分来自读出与正则化。追加完成 `composition_charge_deep` 的2折×2LR，使用相同hidden/dropout、全规模、共同数据与训练规则。输入维度不同，因此这只是读出深度/宽度/正则化对照，不是总参数量完全匹配，更不是单独改变深度的因果实验。追加是在已看48 fit结果后登记，继续属于曝光开发。

| 最终追加证据 | 值 |
|---|---|
| 追加完成/独立复算 | 4 / 4；阶段总数52 / 52 |
| charge-deep选定配置的group-macro H / CDF / 首末bin质量MAE | 0.052186794 / 0.000198165 / 0.002089049 |
| fusion同口径H / CDF / 首末bin质量MAE | 0.050139669 / 0.000192363 / 0.001992132 |
| fusion − charge-deep：ΔH与描述性95%区间 | -0.002047125；[-0.002611766,-0.001497169] |
| 两折H方向：fusion / charge-deep | fold0：0.0505060 / 0.05235366；fold1：0.0497735 / 0.05202003；均改善 |
| 相对较强charge-deep基线的增量与成本解释 | H相对下降3.92%，CDF与首末bin质量误差也改善；融合另需ESMC提取与缓存，不能仅凭小头训练时间判断成本效益 |

**本阶段决策。** 四个追加fit及复算已经结束，关闭本阶段，不追加架构搜索。电荷深头优于电荷小头，融合的相对优势由4.74%缩小为3.92%，但在同hidden/dropout对照下仍保留两折一致的改善；因此保留最佳电荷基线与融合进入后续有限验证。该结果削弱“仅由读出深度/宽度/正则化不同解释全部优势”的说法，不等于完全隔离encoder的因果贡献。实用收益仍需结合提取成本及新C目标确认。不将区间跨0解释为等效，也不把历史建议的5%自动变成已批准晋级线。

## 决策卡2：mean是否丢失了可利用的信息

**依据。** KaML-ESM代码使用目标残基向量预测pKa，不能用其结果为全蛋白mean背书。本轮mean-pLM单独输入仍落后，只约束当前encoder、输入和预算；尚未验证残基级读出无用。

**下一轮最小行动。** 本阶段归档后，如需回答该机制问题，仅保留一个encoder：比较“mean→MLP”与“共享残基MLP→masked mean→输出”。保持合法共同样本、组划分、stop选择、损失、LR机会，记录参数与计算成本；残基mask不得混入padding或特殊tokens。先做限定两折的配对开发比较，出现稳定增量后才扩大，不重开encoder×pool×loss全组合。

**关闭规则。** 报告ΔH、两折方向、CDF/尾质量/长度分层与编码及读出成本。是否有用按预先指定的用途容忍度判断；没有稳定增量则暂挂该分支，不继续靠换更大encoder追分。该对照可解释读出选择，本身不自动形成科学创新。

**ESM3条件分支。** 同checkpoint的纯序列与序列+既有坐标才直接检验结构输入增量；实验结构和预测结构分开。已核官方接口，但已知Byte模型根未找到`esm3-sm-open-v1`权重/manifest，实际加载未完成。只有获取合格checkpoint及配套资产后才做16条加载/成本pilot，再决定是否扩到小型配对面板；不以等待ESM3阻塞当前阶段关闭。

## 决策卡3：历史监督初始化能否加快新C训练

**依据与限制。** KaML已有合成监督预训练→实验标签训练的先例；“电性预测+监督初始化”不能作为本项目首创。历史Atlas可用于试验初始化，但旧顶点p与新面积p不同，T与C输入不同，正迁移尚未得到验证。

**下一轮最小行动。** 先连接新C实际序列、身份关系和同源保护闭包，确认可用的已接受新标签开发快照。按每个新fold排除与其stop/评价对象有关的历史标签，分别产生合法历史初始化；不能用本轮含这些对象的监督权重替代。选同一模型，比较随机初始化与历史初始化，统一新数据量、stop规则和适配训练预算；必要时重置输出头，并固定该策略。旧预训练额外成本单独计入。

**关闭规则。** 同时报告最终H/CDF/尾质量及达到同误差所需的新训练时间，检查负迁移亚群；仅速度收益也可构成工程用途，不能包装为泛化增益。若无稳定收益，取消历史监督初始化，保留本轮用于选型和工程校准。当前全部历史收据仍为`new_C_transfer_permitted=false`，此次阶段关闭不改变该状态。

## 科学创新的收束条件

[KaML-ESM](https://www.nature.com/articles/s41467-026-78406-y)已有序列/pLM电性预测与监督预训练迁移；其输出为逐残基pKa，与本项目SES面积电势分布不同。已读原始证据的深度和最终版SI缺口见调研记录。本阶段不继续等待SI补齐，不声称完成全部论文复现。普通MLP、拼接电荷特征、mean/attention、预训练初始化或全库推理均不单独充当创新点。

| 候选论文贡献 | 可证伪的关闭条件 | 本阶段状态 |
|---|---|---|
| 统一物理定义、面积加权的电势分布资源 | 新标签逐条连接实际物理协议、成功归档与接受收据；面积测度、bins、输入/结构语义清楚；说明相对既有资源新增信息 | 新生产与接受仍独立推进；本轮顶点p结果不替代它 |
| 在低同源泛化下，序列模型提供实用增量 | 新冻结release的合格组划分、强简单基线及公平读出对照；OOF/外部评价与选型曝光分开；误差和成本达到预先约定用途要求 | 本轮取得历史规模证据，尚无新C结论 |
| 表征支持全序列空间的可重复科学发现 | 固定数据库release/序列分母；独立物理参考面板验证C→天然U/实验→预测结构桥接；核心生物学效应超出teacher与surrogate误差，支持域与失败可查 | 未完成；不能由本轮H或扫描数量推出 |

收束的是“哪些claim有证据、哪些需下一步验证”，不是保证发表。若最接近工作已覆盖某项主张，则删除首次性表述，把贡献限定为可核验的资源、评价或新科学结果。
