## 决策

保留直方图梯度提升作为论文传统基线，停止本轮继续扩大树模型搜索。它比 ExtraTrees 略好，但总体与严格 T=U、长序列分层均没有超过已有电荷神经网络；当前最有依据的架构方向仍由神经读出确认实验决定。这里没有证明所有树模型都不行。

## 实验和输出定义

- 先读当前研究 README 与 Byte AGENTS/RUN/STATUS；在 196 个限定历史索引文件中未发现 RF/ExtraTrees/GBDT 已执行记录。未据此声称穷尽所有更早 G1 资产。
- 复用已验 Atlas T→历史顶点概率 p，所有合法行保留；当前任务不使用新 C 面积标签。五折角色为 eval=i、stop=(i+1)%5、其余三折训练。分组和重复 T 权重沿用神经基线。所有缺失值中位数只在训练折拟合，显式保留39列缺失标志；树不需要标准化。
- fold0 初筛：ExtraTrees sqrt(p) leaf1/leaf3，RF sqrt(p) leaf3，ExtraTrees p leaf3，ESMC mean+charge 的 ExtraTrees sqrt(p)，HistGBDT sqrt(p)。均用现有 sklearn1.7.2，没有安装或升级依赖。
- 根据 stop 组宏 H 选最好的 HistGBDT 和 ExtraTrees leaf3，固定配置与 seed1701 补其余四折。HGB stop H=0.053664；ET=0.053863。它们在筛选时最接近且每 fit 成本很低，因此保留两类确认。
- 原生森林联合回归63维 `sqrt(p)`，预测坐标非负截取后平方并归一；p 控制直接回归63维概率均值并归一。HistGBDT 单独拟合63个平方根概率坐标，负值截断再平方归一。**这些是回归构造的合法概率，不是 logits，也不等于 softmax 似然训练。** HGB 负坐标最多占0.0487%，均被明确记录。
- ET/RF 256棵树；入围 ET 的 min_samples_leaf=3、max_features=1.0。HGB 每坐标200轮、15叶、LR=.08、L2=1、127 bins，无额外内部随机 validation 或早停。一个 HGB pipeline fit 含63个单输出模型，不把它描述成一个原生多输出树。
- 六配置是有预算的参考，不是充分超参数搜索。XGBoost/LightGBM/CatBoost 未安装，也没有凭未运行结果判断优劣。一次 fold0/stop1 全局选型再复用配置的五折是已曝光开发评估，不是嵌套无偏测试。

## 验证与成本

14份预测全部从概率重新计算 H/CDF/尾部；概率均非负、有限且归一。每份 roles 核验同组不跨 train/stop/eval、完整训练行无缩减，五折 OOF 每条评价行恰出现一次。

14个独立新进程从 joblib 恢复、重读原始特征并核训练折中位数，每个128条按长度排序覆盖端点，共1,792次预测。最大概率差 1.39×10⁻¹⁶；覆盖50–3,619 aa。保存模型、预测与角色的 hash，源码执行 SHA 在 `results/public/code_provenance.json`。

最多8 CPU线程、峰值RSS11.05 GiB；pipeline fit累计703.64秒，含进程启动/退出的队列累计727.86秒；纯 estimator fit累计228.24秒。开始到完整配对/审计约18.7分钟，未接近2小时上限。没有把 CPU 秒、墙钟或 GPU 忙时混用。

HGB每折压缩模型约10.8MB，缓存特征头推理约5,771–8,436序列/秒；ET约921–932MB、32,610–44,243序列/秒。后者体积明显更大。这里不含特征生成，ESMC 控制还不含 encoder；不同 CPU/GPU 实现的吞吐不能直接视为完整部署速度排名。

公开白名单为 `results/public/` 中聚合 JSON/CSV 和本报告；没有样本/组 ID、序列、标签、逐样本预测、权重或全日志。完整审计和模型留 Byte。此阶段已完成，未留下训练进程。
