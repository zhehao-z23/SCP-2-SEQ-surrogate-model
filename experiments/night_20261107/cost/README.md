# Bounded cost evidence for surrogate scanning

[Report](REPORT.md) separates normal production, one-time validation/development, measured inference, and conditional scan scenarios. [Anonymous summary](night_20261107_cost_public_v3.json) retains all earlier measurements and adds exact historical charge-only OOF timing. [Cascade scenarios](conditional_cascade_cost.json) show CPU and GPU-process resources separately.

The screening utility belongs to historical LPBE/vertex labels; the physical price proxy comes from current NPBE/SES-area production. Their combination is a conditional model, not a validated new-protocol cascade. Unknown labels remain unknown; identification bounds are not confidence intervals. Deterministic 95-input length stratification is not AFDB-wide representative sampling.

The four measurement/census files under `src/` are path/GPU templates derived from executed sources. They require independently authorized private inputs, models, role gates, and fresh resource admission; they are not stand-alone reproduction bundles. Do not disable their guards to run them. The charge aggregation and plotting sources are exact postprocessing files. [Source provenance](source_provenance.json) separates executed-source hashes from template hashes.

Plotting source can regenerate aggregate figures from the public summary, but no image, HTML, checkpoint, sample input, or per-object value is part of this package. Publication is handled separately from creating this candidate.
